# Dance Party

This repository contains a simple command line prototype for the **Dance Party** application. It demonstrates basic features such as selecting dance styles, viewing tutorials, a simulated music player, a competitive dance off mode, and a leaderboard.

## Requirements

* Python 3.8+

No additional dependencies are required as the prototype only uses the Python standard library.

## Running

```bash
python3 src/dance_party.py
```

Follow the menu prompts to explore the features.
